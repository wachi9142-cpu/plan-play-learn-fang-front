# ② Feature Specification — Little Purple Garden Web Application

> เว็บนี้เป็น **Web Application ของโรงเรียน** ไม่ใช่เว็บประชาสัมพันธ์ธรรมดา
> แนวทาง: *Mobile First แต่ระบบต้องขยายความสามารถขึ้นตามพื้นที่หน้าจอ ไม่ใช่เพียงย่อ Desktop ลงมาเป็น Mobile*

## 1. ห้องเรียน + นักเรียน (ไม่ฝังในโค้ด)
- ห้องเริ่มต้น 15 ห้อง (seed ครั้งแรก) — Nursery ×3, เตรียมอนุบาล ×3, อ.1 ×3, อ.2 ×3, อ.3 ×3 — **ครู/Admin เพิ่ม แก้ ปิด ลบ ห้องได้เองจากหน้าเว็บ** รวมถึง ⭐ ห้องเรียนพิเศษ (ศิลปะ ดนตรี เสริมทักษะ เรียนรวม โครงการ)
- แต่ละห้องมี 2 ชื่อ: **รหัสห้องจริง** (`อนุบาล 3/1`, `Nursery / ห้อง 1`) ใช้อ้างอิงในระบบ และ **ชื่อเล่นห้อง** (`🌈 ห้องพี่สายรุ้ง`) แสดงผล เปลี่ยนได้ภายหลัง
- ชื่อเล่นเริ่มต้น: 🦋 เจ้าผีเสื้อน้อย · 🐝 เจ้าผึ้งน้อย · 🐛 เจ้าหนอนน้อย · 🐰 น้องกระต่าย · 🐥 น้องลูกเจี๊ยบ · 🐞 น้องเต่าทอง · 🐧 น้องเพนกวิน · 🐻 น้องหมีน้อย · 🐼 น้องแพนด้า · 🌻 ดอกทานตะวัน · 🌼 ดอกเดซี่ · 💜 ดอกลาเวนเดอร์ · 🌈 พี่สายรุ้ง · 🌳 พี่ต้นไม้ใหญ่ · ⭐ พี่ดวงดาว

## 4b. 🎮 เกมการศึกษา — ระดับความยาก
- **ทุกเกม** เลือก 🟢 ง่าย / 🟡 ปานกลาง / 🔴 ยาก ก่อนเล่น (สร้างอัตโนมัติจากข้อมูลเกมชุดเดียวใน `src/lib/game-levels.ts`: จำนวนคู่/ข้อ/ตัวเลือก · โหมดเติมตัวที่หายไป · ตัวช่วย · จับเวลาเฉพาะระดับยาก)
- 🧠 หมวดใหม่ "ตรรกะและการคิด": **เกมเลื่อน (Sliding Puzzle)** 3×3 ตัวเลข 1–8 · ก–ซ · A–H · ภาพสัตว์ · สี · รูปทรง (กลไกเดียวกัน ขยาย 4×4 ได้) — ง่าย/กลาง/ยาก = สลับจากภาพที่ถูกต้อง 4/14/40 ครั้ง (แก้ได้เสมอ) · ไม่เน้นจับเวลา
- ⭐ ผลลัพธ์แบบเด็กเล็ก: 2–5 ดาว + คำชม (🎉 เยี่ยมเลย · ⭐ ทำได้ดีมาก · 💪 เกือบแล้ว · 🌱 ลองอีกครั้ง) — ไม่มีคำว่า ตก/ผิด/แพ้
- 📊 จำผลการเล่นต่อเด็ก (ชื่อ · เกม · ระดับ · ดาว · ครั้งที่เล่น · เวลา · วันที่) ที่ `/games/progress` — **ไม่จัดอันดับ**
- 👤 **โปรไฟล์ผู้เล่น (หลายคนต่อ 1 ครอบครัว)**: ชื่อ + อายุ → ช่วงวัยอัตโนมัติ 🐣 2–3 ปฐมวัยเล็ก · 🌱 4–6 อนุบาล · 📚 7–12 ประถม · 🔎 13–15 ม.ต้น · 🎓 16–18 ม.ปลาย · 🧑 18+ (`src/lib/age-bands.ts`) · "👋 ใครกำลังเล่นอยู่?" เลือกคนก่อนเล่น · Avatar ต่อคน · ประวัติ/ระดับแยกคน · เกมแนะนำตามช่วงวัย (รองรับเกมประถม/มัธยม/Coding ในอนาคตด้วยโครงสร้างเดิม)
- 📴 **ออนไลน์/ออฟไลน์ (PWA)**: `public/sw.js` + `manifest.webmanifest` · ปุ่ม 🌐 เล่นออนไลน์ / 📥 ดาวน์โหลดไว้เล่นออฟไลน์ (ครั้งเดียว อยู่ในเครื่องจนกดลบ) · ส่วน "📴 เกมที่เล่นออฟไลน์" (เกม · ระดับ · สถานะ · เล่นแล้ว · ขนาด · ▶️ เล่น / 🗑️ ลบ) · ผลการเล่นเก็บในเครื่องก่อน → 🔄 ซิงก์เมื่อออนไลน์ (`NEXT_PUBLIC_GAME_API`) · สถานะ 🟢 ออนไลน์ / 🟠 กำลังซิงก์ / 🔴 ออฟไลน์
- 👩‍🏫 ครูกำหนดระดับต่อห้อง/ต่อเด็ก (ทุกเกมหรือรายเกม) · 🔄 ปรับความยากอัตโนมัติ เปิด/ปิดได้ (5 ดาว 2 ครั้งติด → แนะนำขึ้น · ยาก ≤2 ดาว 2 ครั้งติด → แนะนำลง)

## 4c. 💻 Coding & Logic (เกม + ใบงาน)
- หมวดเกมใหม่ **💻 Coding & Logic** เพิ่มเกมได้เรื่อย ๆ (`src/data/games-coding.ts`) · ประเภทเกมขยายเป็น จับคู่ · Puzzle · ลำดับ · คณิตศาสตร์ · ภาษา · วิทยาศาสตร์ · Coding & Logic · Creative · ทักษะมาตรฐาน (`game-skills.ts`): การสังเกต · การแก้ปัญหา · การคิดเป็นลำดับ · การคิดเชิงตรรกะ · Computational Thinking · Coding
- engine ใหม่: **grid-path** (เรียงคำสั่ง ⬆️➡️ กด ▶️ ตัวละครเดินทีละก้าว · 🔁 ทำซ้ำ · สิ่งกีดขวาง · โหมดดูเส้นทาง/แก้บั๊ก · ผิดทาง = "🌱 ลองใหม่อีกครั้งนะ") · direction · pattern · condition (If/Then) · quiz (ตรรกะ/ทายผลลัพธ์/หาบั๊ก) + sort (เรียงขั้นตอน/flowchart)
- 🌱 ปฐมวัย 7 เกม (กระต่าย ผึ้ง รถ เรียงคำสั่ง ทิศทาง ลำดับขั้นตอน Pattern) · 📚 ประถม 7 เกม (Block Coding · Loop · Debugging · เขาวงกต · If/Then · Sequence · Algorithm) · 🔎 มัธยม 7 เกม (Logic · Algorithm · Debug Code · Flowchart · Block ขั้นสูง · Challenge · โจทย์โปรแกรม) — ทุกเกมได้ 3 ระดับ/ออฟไลน์/บันทึกผล/โปรไฟล์อัตโนมัติ · คลังเกมกรองตามช่วงวัยได้
- **📝 ใบงาน Coding & Computational Thinking** 27 ใบ (`worksheets-coding.ts`) template ใหม่: path (ตารางเดิน + บัตรคำสั่ง) · commands (ช่อง ❓ / คำสั่งผิด) · pattern-sheet · qa (คำถาม + โค้ด + บรรทัดตอบ) · ทุกใบมี **เหมาะกับอายุ** · หน้าใบงานกรองได้ตาม 👶 อายุ · หมวด · 🧠 ทักษะ · หมวดเพิ่ม วิทยาศาสตร์ ธรรมชาติ
- **เชื่อมทั้งระบบ**: 📖 แผน "🐰 กระต่ายนักผจญภัย" (หน่วย Coding) → 🎮 เกม → 📝 ใบงาน (worksheet.gameIds ↔ เกมแสดง "ใบงานที่คู่กัน") → 🎨 ผลงาน

## 4d. 📚 ระบบจัดการหลักสูตร (Curriculum Management)
- **เพิ่มหลักสูตรได้ไม่จำกัด** (`/curriculum`): ชื่อ · ปี พ.ศ. · ระดับการศึกษา · รายละเอียด · สถานะ 🟢 ใช้งาน / 🟡 รอตรวจสอบ / ⚪ เก็บประวัติ · วันที่ประกาศ · หมายเหตุ · ผู้เพิ่ม · ไฟล์หลัก (PDF) + เอกสารประกอบ (Word · PPT · รูป · อื่น ๆ เก็บใน IndexedDB `curriculum:<id>`)
- **📖 ตัวอ่าน PDF ในเว็บ** (`PdfReader`, pdfjs-dist + `/pdf.worker.min.mjs`): เปลี่ยนหน้า · เลขหน้า · 🔎 Zoom · 🔍 ค้นหาข้อความทั้งเล่ม (คลิกผลลัพธ์ไปหน้านั้น) · 📌 Bookmark · เต็มจอ · ปุ่มลูกศรซ้าย/ขวาเลื่อนหน้า
- **🧩 โครงสร้างข้อมูลรายฉบับ** (แก้ไขได้): มาตรฐาน → ตัวบ่งชี้ → สภาพที่พึงประสงค์ (ระบุช่วงอายุ) · ประสบการณ์สำคัญ (แยกด้าน) · สาระที่ควรเรียนรู้ — ข้อมูล 2560 กับ 2570 **แยกกันคนละชุด** (คัดลอกจากฉบับอื่นมาเป็นจุดตั้งต้นได้) · มีข้อมูลตั้งต้นย่อของหลักสูตรปฐมวัย พ.ศ. 2560 (มฐ 1–12) ให้แก้/เติมตามเอกสารจริง
- **ใน Garden Studio**: rail 📚 หลักสูตร → เลือกฉบับที่ใช้ (บันทึกใน `doc.links.curriculumId` — แผนเก่ายังอ้างอิงฉบับเดิมเสมอ) · ติ๊กเลือกสภาพที่พึงประสงค์/ประสบการณ์สำคัญ/สาระที่ควรเรียนรู้ แล้วกด "⬇️ ใส่ลงแผน" → ได้หัวข้อ + รายการในเอกสาร · **Split View**: ซ้าย = แผน ขวา = PDF หลักสูตร · ชิปบนหัวเอกสารกดเปิดอ่านได้ทันที
- Flow: Admin เพิ่มหลักสูตร → อัปโหลด PDF → จัดโครงสร้าง → ครูเลือกฉบับตอนสร้างแผน → เปิด PDF คู่กับแผน → เลือกมาตรฐาน/ตัวบ่งชี้ฯ → บันทึกแผนพร้อมระบุฉบับที่ใช้ · **ตรวจข้อความกับ PDF ต้นฉบับเสมอ** (ระบบไม่ดึงข้อความจาก PDF อัตโนมัติ)

## 5. 📚 ระบบการเรียนรู้ (ความสัมพันธ์ข้อมูล)
```
กำหนดการสอน (Schedule) → หน่วย/เรื่อง (Unit) → แผนการจัดประสบการณ์ (LessonPlan)
   → กิจกรรม (Activity) → เกม / ใบงาน / สื่อ (Game · Worksheet · Media)
   → งานของเด็ก (Assignment/Submission) → ผลงาน / Portfolio
```
เพิ่มข้อมูลใหม่ = เพิ่มระเบียนในโครงสร้างเดิม ไม่ต้องสร้างระบบใหม่

## 7b. 🌱 “เวลาของสวนวันนี้” (Global Thailand Clock)
นาฬิกา Real-time ใน **Header หลัก** แสดงทุกหน้าของระบบ · โซนเวลา `Asia/Bangkok` (UTC+7) · รูปแบบ 24 ชั่วโมง (`08:30` · `19:45`) · อัปเดตทุกวินาที
- เดสก์ท็อป/แท็บเล็ต: `🌱 19:20 น.` พร้อมคำว่า **“เวลาของสวนวันนี้”** ตัวเล็กใต้เวลา (เป็นส่วนหนึ่งของแบรนด์ ไม่ใช่นาฬิกาสำเร็จรูป) — มือถือย่อเหลือ `🌱 19:20` ข้างปุ่มเมนู ไม่ลอยทับเนื้อหา
- กดที่นาฬิกา → “🌱 เวลาของสวนวันนี้” + 🇹🇭 เวลาในประเทศไทย: เวลาพร้อมวินาที · วัน/วันที่แบบไทย · โซนเวลา + UTC offset · แหล่งอ้างอิงเวลา
- **ไม่อิงนาฬิกาเครื่องอย่างเดียว**: ซิงก์ส่วนต่างจากเวลาเซิร์ฟเวอร์ (header `Date`, ชดเชย RTT) ตอนเปิดและทุก 30 นาที · ออฟไลน์จึงถอยไปใช้เวลาเครื่องและแจ้งสถานะ 🟡
- รองรับหลายโซนเวลาตั้งแต่แรก (`src/lib/clock.ts` → `TIMEZONES`) — เพิ่มญี่ปุ่น/อังกฤษ/สหรัฐฯ ได้โดยไม่แก้ระบบหลัก ค่าเริ่มต้น = 🇹🇭 ประเทศไทย

- ปิดแล้วจางหายใน 0.6 วิ · `prefers-reduced-motion: reduce` → ไม่เล่นเลยและปุ่มถูกล็อกพร้อมคำอธิบาย · ไม่พิมพ์ลงกระดาษ

## 🎯 Activity Mode — ปิดเอฟเฟกต์ในหน้าที่ต้องลงมือทำ

> "เอฟเฟกต์มีไว้สร้างบรรยากาศ ไม่ใช่รบกวนการเรียนรู้"

ระบบตรวจเส้นทางของหน้าอัตโนมัติ ([activity-mode.ts](../src/lib/activity-mode.ts)) แล้วตั้ง `<html data-activity="on">` · ชั้นเอฟเฟกต์จะไม่ถูกสร้างเลย (ไม่ใช่แค่ซ่อน) และมี CSS กันอีกชั้น — **ธีมสว่าง/มืดยังทำงานตามปกติ**

| โหมด | ตัวอย่างหน้า | เอฟเฟกต์ |
|---|---|---|
| landing · informational · listing · detail | หน้าแรก · เกี่ยวกับ · ประชาสัมพันธ์ · ปฏิทิน · กิจกรรม · โครงการ · ห้องสมุด · แฟ้มผลงาน · รายการเกม/ใบงาน · ตั้งค่า | 🟢 เปิด |
| activity | `/canvas/**` วาดรูป · `/worksheets/[id]` ทำใบงาน | 🔴 ปิด |
| interactive | `/games/[id]` กำลังเล่นเกม · `/search` | 🔴 ปิด |
| editor | `/studio/**` · `/curriculum/[id]` · `/development` · `/admin` | 🔴 ปิด |
| classroom | `/online-classroom/**` | 🔴 ปิด |

- เพิ่มหน้าใหม่ที่ต้องปิด = เพิ่ม 1 บรรทัดใน `ACTIVITY_ROUTES`
- หน้าผสม (มีทั้งข้อมูลและกิจกรรม) ตั้ง `document.documentElement.dataset.activity = "on"` เองได้ CSS จะปิดเอฟเฟกต์ให้ทันที
- `/games/progress` และ `/curriculum` (หน้ารายการ) ยังเปิดเอฟเฟกต์ เพราะเป็นหน้าดูข้อมูล

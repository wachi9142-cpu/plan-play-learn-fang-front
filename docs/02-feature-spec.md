# ② Feature Specification — Little Purple Garden Web Application

> เว็บนี้เป็น **Web Application ของโรงเรียน** ไม่ใช่เว็บประชาสัมพันธ์ธรรมดา
> แนวทาง: *Mobile First แต่ระบบต้องขยายความสามารถขึ้นตามพื้นที่หน้าจอ ไม่ใช่เพียงย่อ Desktop ลงมาเป็น Mobile*

## 1. ห้องเรียน + นักเรียน (ไม่ฝังในโค้ด)
- ห้องเริ่มต้น 15 ห้อง (seed ครั้งแรก) — Nursery ×3, เตรียมอนุบาล ×3, อ.1 ×3, อ.2 ×3, อ.3 ×3 — **ครู/Admin เพิ่ม แก้ ปิด ลบ ห้องได้เองจากหน้าเว็บ** รวมถึง ⭐ ห้องเรียนพิเศษ (ศิลปะ ดนตรี เสริมทักษะ เรียนรวม โครงการ)
- แต่ละห้องมี 2 ชื่อ: **รหัสห้องจริง** (`อนุบาล 3/1`, `Nursery / ห้อง 1`) ใช้อ้างอิงในระบบ และ **ชื่อเล่นห้อง** (`🌈 ห้องพี่สายรุ้ง`) แสดงผล เปลี่ยนได้ภายหลัง
- ชื่อเล่นเริ่มต้น: 🦋 เจ้าผีเสื้อน้อย · 🐝 เจ้าผึ้งน้อย · 🐛 เจ้าหนอนน้อย · 🐰 น้องกระต่าย · 🐥 น้องลูกเจี๊ยบ · 🐞 น้องเต่าทอง · 🐧 น้องเพนกวิน · 🐻 น้องหมีน้อย · 🐼 น้องแพนด้า · 🌻 ดอกทานตะวัน · 🌼 ดอกเดซี่ · 💜 ดอกลาเวนเดอร์ · 🌈 พี่สายรุ้ง · 🌳 พี่ต้นไม้ใหญ่ · ⭐ พี่ดวงดาว

## 2. 💻 Online Classroom
| ความสามารถ | รายละเอียด |
|---|---|
| ครูควบคุมห้อง | ผู้เข้าห้องต้องมาจากลิงก์/รหัสเชิญ และ**ครูกดอนุญาต**ก่อนเข้าห้องเรียนสดเสมอ · นำออก · ปิด/เปิดไมค์-กล้องรายคน |
| ผู้ปกครองอยู่ร่วมกับเด็ก | เข้าห้อง "แบบไม่เปิดกล้อง" ได้ ไม่บังคับเปิดกล้อง/ร่วมตลอดเวลา |
| เรียนสด | WebRTC (mesh) + relay ws เป็น signaling · แชร์หน้าจอ/สื่อ · ยกมือ |
| บันทึกการสอน | ⏺ MediaRecorder → คลิป .webm เก็บอัตโนมัติในคลังย้อนหลัง (🎥) พร้อมประวัติคาบเรียน |
| ฟิลเตอร์/สติกเกอร์ | หูแมว มงกุฎ หน้าหมา กระต่าย ดาว ดอกไม้ อารมณ์ · **Teacher Control Mode: งด/อนุญาตรายบุคคล** |
| ⭐ ระบบดาว | ให้ดาวจากหน้าจอสด/แท็บดาว พร้อมเหตุผล (แก้/ลบได้) สะสมในโปรไฟล์เด็ก · เป็นแรงเสริมเชิงบวก |
| 💬 แชตประจำห้อง | ประเภท: ข้อความ · 📣 แจ้งข่าว · 📝 การบ้าน · 🎨 ลิงก์กิจกรรม · 📅 กำหนดการ · 📎 ส่งไฟล์/ส่งงาน · 🔗 ลิงก์ · กรองตามบทบาท |
| สถานะ | 🌐 Connection 🟢🟠🔴 (จาก RTC stats/ออนไลน์) แยกจาก 🙋 Participation 🟢🟡🔴 (จากการโต้ตอบล่าสุด + ปุ่ม "เช็คชื่อ") |
| 📚 เรียนย้อนหลัง | อัลบั้ม 4 ประเภท 🖼️ ภาพ · 🎥 วิดีโอ · 📄 ไฟล์ · 📦 อื่น ๆ · กรอง 📅 เดือน · 📖 หน่วย · 🎯 กิจกรรม · ค้นหา · หมายเหตุถึงผู้ปกครอง |
| 🧑‍🏫 Teacher Dashboard | ทุกห้อง: จำนวนเด็ก · ออนไลน์ · สัญญาณ · ไม่ร่วมกิจกรรม · ดาว · คลัง · ปุ่มลัด เริ่มห้อง/เชิญ/ดาว/คลัง/แชต |

## 3. 🌱 Garden Studio
สร้างเอกสาร (แผน/กำหนดการ/ใบงาน/สื่อ/สไลด์ 16:9/สเปรดชีต+สูตร) · บล็อก (หัวข้อ ย่อหน้า รายการ ตาราง รูป ไฟล์ callout ฟิลด์) · **ตารางแบบ Word** (เพิ่ม/ลบแถว-คอลัมน์ · ลากปรับกว้าง/สูง หรือพิมพ์ตัวเลข · รวม/แยกเซลล์ · จัดซ้าย-กลาง-ขวา/บน-กลาง-ล่าง · ฟอนต์/ขนาด/สี/พื้นหลังรายเซลล์ · เส้นขอบ · รูปในเซลล์ · ลากขนาดทั้งตาราง) · ฟอนต์ไทย + อัปโหลด .ttf/.otf · รูป/ไฟล์แนบ · Auto-save + ออฟไลน์ · สถานะเอกสาร · **📥 ดาวน์โหลด**: PDF (แนะนำ) · Word · PNG · JPG · PowerPoint · Text · ZIP · พิมพ์

## 4. 🎨 Garden Canvas
วาดด้วยเมาส์/ปากกา/นิ้ว · ดินสอ แปรง เส้นตรง รูปทรง (สี่เหลี่ยม วงกลม สามเหลี่ยม ดาว ทึบ/โปร่ง) · เทสี · ข้อความ · รูปภาพ (ย้ายได้) · ยางลบ (มองเห็นขนาด เล็ก/กลาง/ใหญ่) · ล้างทั้งหมด · Undo/Redo · แม่แบบกิจกรรม 8 แบบ (สวนของเรา ลากเส้น ตัวเลข ตัวอักษร เติมสี บ้านในฝัน นิทาน) · **วาดร่วมกัน real-time** (ห้อง + รหัส 6 ตัว · เห็นเคอร์เซอร์/สีของแต่ละคน · รายชื่อใครกำลังวาด) · บันทึก PNG/JPG/PDF · เก็บในแฟ้มผลงานเด็ก · เผยแพร่ในหน้าผลงานเด็ก

## 5. 📚 ระบบการเรียนรู้ (ความสัมพันธ์ข้อมูล)
```
กำหนดการสอน (Schedule) → หน่วย/เรื่อง (Unit) → แผนการจัดประสบการณ์ (LessonPlan)
   → กิจกรรม (Activity) → เกม / ใบงาน / สื่อ (Game · Worksheet · Media)
   → งานของเด็ก (Assignment/Submission) → ผลงาน / Portfolio
```
เพิ่มข้อมูลใหม่ = เพิ่มระเบียนในโครงสร้างเดิม ไม่ต้องสร้างระบบใหม่

## 6. 🧸 Avatar (ใช้ร่วมกันทั้งระบบ)
โปรไฟล์ไม่ใช้รูปเด็กจริงเป็นหลัก — อีโมจิ/การ์ตูน + สีพื้น หรืออัปโหลดภาพวาด/AI illustration · ใช้ในโปรไฟล์ ห้องเรียน แชต งาน Portfolio ดาว Online Classroom · แก้ได้ภายหลัง · ผลงานจริงอัปโหลดได้แต่กำหนดสิทธิ์ผู้เห็น

## 7. โมดูลถัดไป (ออกแบบโครงสร้างไว้แล้ว)
- **Garden Library** — คลังรวม รูป/วิดีโอ/PDF/Word/PPT/เสียง/สื่อ/ใบงาน จากทุกระบบ กรองตามประเภท/ห้อง/หน่วย
- **Portfolio** — ผลงาน + งานที่ส่ง · หมวดหมู่ · วันที่ · ความคิดเห็นครู · Private / แสดง Gallery
- **พัฒนาการ 4 ด้าน** — ร่างกาย · อารมณ์-จิตใจ · สังคม · สติปัญญา · บันทึกรายเด็ก · ผู้ปกครองเห็นเฉพาะลูกตัวเอง
- **Admin / CMS** — เพิ่ม/แก้/ลบ ห้อง ครู นักเรียน ผู้ปกครอง กำหนดการ หน่วย แผน กิจกรรม เกม ใบงาน สื่อ โครงการ ข่าว ประกาศ ปฏิทิน รูป วิดีโอ ไฟล์ Avatar โดยไม่แก้โค้ด

## 8. Responsive / อุปกรณ์
- รองรับ iPhone · Samsung · OPPO · Xiaomi/Redmi · vivo · Huawei · Pixel · iPad/iPad Pro · Galaxy Tab · Windows/Mac/Chromebook · จอ Full HD/สูง
- Breakpoints ต่อเนื่อง (320 → 1920+) ไม่ล็อกแค่ 3 ขนาด · ปุ่มขนาดนิ้ว (≥ 40px) · Touch: tap/swipe/scroll/drag&drop · Canvas รองรับ Apple Pencil/Stylus/นิ้ว (pointer events, `touch-none`)
- ห้ามเกิด: ตัวหนังสือล้น · ปุ่มหลุดจอ · ตารางทำเว็บพัง (ตารางเลื่อนในกรอบ) · รูปยืด · เมนูทับ · Modal ปิดไม่ได้ · ต้องซูมเพื่อกด · horizontal scroll โดยไม่จำเป็น
- ทดสอบ Chrome · Safari (iPhone/iPad แยก) · Edge · Firefox

## 9. โครงสร้างพื้นฐานปัจจุบัน → ระบบจริง
| ตอนนี้ (พร้อมใช้ในเครื่อง/LAN) | เมื่อขึ้นเซิร์ฟเวอร์จริง |
|---|---|
| localStorage / IndexedDB ต่อเครื่อง | ฐานข้อมูล (PostgreSQL/Supabase/Firebase) ผ่าน API |
| relay ws (`npm run canvas-server` พอร์ต 3003) | WebSocket service เดิม + STUN/TURN หรือบริการวิดีโอ (LiveKit/Daily) สำหรับห้องใหญ่ |
| "คุณคือใคร" ระบุเอง | OAuth (Google/Facebook) + บทบาทจากฐานข้อมูล |
| กล้อง/ไมค์ต้องเปิดผ่าน https/localhost | ใช้ HTTPS ทั้งระบบ |

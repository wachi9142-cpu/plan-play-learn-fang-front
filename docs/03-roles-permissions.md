# ③ User Roles & Permissions

| บทบาท | ใครบ้าง | สิทธิ์หลัก |
|---|---|---|
| 👑 **Admin** | ผู้ดูแลระบบ/ผู้บริหาร | จัดการทุกอย่าง: ห้องเรียน ชื่อเล่นห้อง ครู นักเรียน ผู้ปกครอง เนื้อหาทุกประเภท Avatar สิทธิ์ผู้ใช้ ตั้งค่าเว็บ |
| 👩‍🏫 **Teacher** | ครูประจำห้อง/ครูพิเศษ | จัดการห้องที่ได้รับมอบหมาย: เชิญ/อนุญาต/นำออก · ควบคุมไมค์-กล้อง-ฟิลเตอร์ · เริ่ม/บันทึกคาบสด · ให้ดาว/แก้เหตุผล · โพสต์แชตทุกประเภท · เพิ่ม/ลบคลังย้อนหลัง · สร้าง/แก้ แผน กำหนดการ ใบงาน สื่อ (Studio) · เผยแพร่ผลงานเด็ก · บันทึกพัฒนาการ · สร้าง/ตั้งค่า/ปิดห้อง (รวมห้องพิเศษ) |
| 👨‍👩‍👧 **Parent** | ผู้ปกครองของเด็กในห้อง | เข้าห้องเมื่อครูเชิญ+อนุญาต · เข้าเรียนสดหรือดูย้อนหลัง (ไม่บังคับ) · แชต (ข้อความ/ส่งงาน/ไฟล์/ลิงก์) · ดูดาว ผลงาน พัฒนาการ **เฉพาะบุตรหลานของตน** · ดาวน์โหลดใบงาน/ไฟล์ที่ครูเผยแพร่ให้ห้อง · แก้ Avatar ของลูก |
| 👧 **Student** | นักเรียน | ใช้เฉพาะข้อมูลของตัวเอง: เข้าห้องสด (ครูอนุญาต) · ยกมือ · เช็คชื่อ · สติกเกอร์ (ถ้าครูอนุญาต) · Garden Canvas · ดูดาว/ผลงานของตัวเอง · ส่งงานผ่านแชต |
| 🌐 **Visitor** | บุคคลทั่วไป | ดูข้อมูลสาธารณะเท่านั้น: หน้าแรก เกี่ยวกับ เมนู ปฏิทิน กิจกรรม ข่าว ติดต่อ เกม ใบงาน สื่อ ผลงานที่ครู**เลือกเผยแพร่** |

## ข้อมูลที่ต้อง **ไม่เปิดเป็นสาธารณะ**
ข้อมูลเด็ก (ชื่อเต็ม วันเกิด) · รูปเด็กจริง · ผลงานที่ไม่ได้เลือกเผยแพร่ · บันทึกพัฒนาการ · ข้อมูลผู้ปกครอง (เบอร์ อีเมล ที่อยู่) · แชตในห้อง · คลิปการสอน · รหัสเชิญห้อง

## แนวทางเทคนิค
- บทบาทผูกกับบัญชี (OAuth Google/Facebook → user.role + ห้องที่สังกัด) · Instagram ใช้ได้เฉพาะแสดงฟีด ไม่ใช่ล็อกอิน
- ทุก API ตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์ (ไม่ใช่แค่ซ่อนปุ่ม) · ไฟล์ส่วนตัวใช้ signed URL หมดอายุ
- ปัจจุบัน (ยังไม่มี backend) ระบบใช้ "คุณคือใคร" ระบุเอง — สำหรับทดลองในเครื่อง/LAN เท่านั้น
